# Vibe Client — Release v1.0.0 (Lunar & Badlion Tier)

## Release Summary
Vibe Client has reached production release readiness with a complete UI/UX overhaul matching top-tier competitive Minecraft clients (Lunar Client & Badlion Client).

### Key Features & Enhancements
1. Lunar / Badlion Tier UI & ClickGUI:
   - Obsidian glass aesthetic with neon violet-to-cyan gradient blooms and animated glows.
   - Clean category rails, instant module search filtering, and custom keybind/status overlays.
2. Smart Version Management & Vanilla Fallback:
   - Supported (Client) Tab: Automatically filters for the supported Minecraft 1.21 family (1.21.1+), bundling all Vibe Client optimizations, Fabric loader, and client-side mods.
   - Unsupported (Vanilla) Tab: Displays older/other versions with a warning banner, allowing players to launch Minecraft in pure Vanilla mode without client mods directly from the launcher.
3. Performance & FPS Boost:
   - Built-in Sodium/Lithium-class performance packs and Low FPS Protection.
4. Cross-Platform Installers:
   - Windows Java Swing GUI Installer / MSI package.
   - Linux shell runner & macOS command runner.
5. Documentation & DevLog:
   - Fully documented in DEVLOG.md and README.md.

Status: Build successful, verified via Gradle, fully ready for distribution and production play.
